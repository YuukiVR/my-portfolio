# Nino Diaz — Portfolio

Temporary single-page portfolio homepage for Nino Diaz.

The homepage now includes a `My works` entry point to `works.html`, with an `AI Video Creation` tab and placeholders for future projects.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

The design intentionally uses only two colors, defined at the top of `styles.css`:

- `--ink`
- `--paper`
